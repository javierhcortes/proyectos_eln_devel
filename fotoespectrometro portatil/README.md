## Foto-Espectrometro portatil

El objetivo del proyecto es fabricar un foto espectrometro portatil con n baterias

Se debe considerar un input de luz con un conector de fibra optica,
un lente colimador, una rejilla de difraccion y un sensor ccd lineal.

En una priemra instancia usaremos una camara web sin filtro infrarojo para obtener la luz difractada con software Theremio spectometer. Luego de calibrar la parte mecanica y optica implementaremos el sensor  ccd lineal.

En un tercer paso necesitamos que se procese internamente y muestre en una pantalla el resultado

Por ultimo diseñaremos parA LOS requerimientos de energía
